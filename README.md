# 🎬 CSS Animation Showcase

A simple and interactive HTML & CSS project that demonstrates different types of CSS animations. This project includes color change, movement, rotation, pulse, fade, loading spinner, square path animation, and a Google-style bouncing dots animation.

## 📌 Features

- 🎨 Color Change Animation
- ⬆️ Move Animation
- 🔄 Rotate Animation
- 💓 Pulse (Scale) Animation
- 🌫️ Fade Animation
- ⏳ Loading Spinner
- ⬜ Square Path Animation
- 🔵 Google-style Bouncing Dots Animation
- Clean and Attractive Layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- CSS Keyframes
- Flexbox

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
